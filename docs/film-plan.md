- 「我想为这个片子单独做一个网站，去讲这个片子……那个片子的拆解，可能包括制作过程、流程、心得体会，做一些拓展，点进去就能够去看。因为只有这样才能做不同网页之间的衔接。」
- 「确保一定要保留原来的画质。」
- 「我会把心得体会给到你，你梳理一下，结合内容，自己去做一个网站。」片名、背景、思路、心得由他提供；**还没给**，不要编。

## 要做的三件事

### 1. 片子自己的网站（新仓库）

- 和 VoiceFlow、万象成文一样单独一个仓库、一个网址：`qinxujunai.github.io/<片名英文或拼音>/`，GitHub Pages 发布。仓库名等他定片名后再建。
- 结构（Apple 故事页的写法，先片子、后讲解）：
  1. 片名 + 一句话；片子本身在第一屏（封面图 + 播放）。
  2. 背景与思路：为什么拍、想表达什么（他的话，梳理结构，不改意思）。
  3. 制作过程与流程：用了哪些 AI 工具、每一步怎么做（只写他给的事实）。
  4. 心得体会：他的原话为主，分节，标题用结论句。
  5. 拓展：有素材才放（分镜、前后对比、提示词）；没有就不放。
  6. 「还差什么」或「下一部想做什么」（按他的意思，没有就不写）。
  7. 页脚「秦徐俊的作品 ↗」回到 `https://qinxujunai.github.io/`（和 VoiceFlow、万象成文的页脚一致）。
- 规矩与个人网站相同：零外部请求（不嵌 B 站等播放器，只能放「在 B 站看 ↗」链接）、系统字体、深浅色、手机优先、无障碍 AA、不编数字、提交只署他本人。

### 2. 视频文件：保留原画质

- **不重新编码。** 只做一次无损的「快速开始」处理，把 MP4 的索引（moov）挪到文件开头，点了就能边下边播：
  ```
  ffmpeg -i 原片.mp4 -map 0 -c copy -movflags +faststart film.mp4
  ```
  处理后用 `ffmpeg -i X -map 0 -f streamhash -` 对比原片和 film.mp4，每条流的哈希必须一样（证明画面、声音一个字节没变），把两个哈希写进交接日志。
- 先 `ffprobe` 看编码：
  - H.264 + AAC 的 MP4：直接用，所有浏览器都能放。
  - HEVC（H.265）、ProRes 或 .mov：部分浏览器（Windows 上的 Chrome/Edge、部分安卓）放不了。**先问他**：保留原片作为下载，同时另出一份高码率 H.264 用来在网页播放？不能擅自压缩。
- 大小：GitHub 单个文件上限 100 MB（超过 50 MB 会有警告，可以推），整站上限 1 GB。**不能用 Git LFS**：GitHub Pages 不提供 LFS 文件，网页会拿到一个指针文件。
- 只存一份：视频放在**片子的仓库**里（例如 `media/film.mp4`）。个人网站用同域的根路径 `/<仓库名>/media/film.mp4` 引用，仍是同源、零外部请求；个人网站仓库不放这 60 MB（它每 6 小时有统计机器人提交，仓库要保持轻）。
- 每换一次视频，仓库历史就多 60 MB。定稿后再推，不要反复推中间版本。
- 播放器：`<video controls playsinline preload="none" poster="封面.webp">`，封面是片子里的一帧（webp，100 KB 以内）。不自动播放有声视频；手机上点了才开始下载。
- 国内访问 GitHub Pages 有时慢：如果他也传了 B 站，在片子下方加一个「在 B 站看 ↗」文字链接作为备选。

### 3. 个人网站首页：换掉「AI 视觉」

- 位置：现在的 `visual()`（经历后面、推荐前面，浅灰底）。换成「片名 + 一句话 + 封面/播放器 + 一行事实 + 「这部片子怎么做的 ↗」（去片子网站）」。
  - 片子网站是另一个网站，所以链接用 ↗（链接规则见 AGENTS.md）。
  - 想清楚它该不该升到「作品」区：他说这部片子「呈现出了我基本所有东西」，可以考虑放进作品区（作品区主张是「让 AI 做的东西，靠得住」，要看片子的讲法是否契合）；拿不准就先放在原 AI 视觉的位置。
- 原画廊的 AI 图片和最后 4 张实拍一起撤下（`content.mjs` 的 `visual`、`photos`，`assets/media/` 里只被画廊用到的图删掉，`src/media.json` 同步）。
- 要同步改：
  - `scripts/build.mjs`：`visual()` 换成影片区块；首页 `<head>` 不预加载视频和封面以外的东西。
  - `assets/site.js`：画廊翻页、懒加载转 eager 的代码如果不再用就删掉；视频播放时导航栏不要挡住控件。
  - `assets/site.css`：删掉画廊样式，加影片区块样式；体积预算（44 KB）不变。
  - `scripts/check.mjs`：视频不在 `assets/media/`，不计入 3000 KB 图片预算；站内资源检查要允许 `/<仓库名>/media/film.mp4` 这个同域根路径（本地 `npm run serve` 没有这个文件，检查里注明只在线上验证）。
  - `scripts/qa.mjs`：首页加一条「视频 `preload=none`、首屏没有下载视频」的检查；弱网 LCP 仍要 < 2.5 s。
  - AGENTS.md 首页结构 5.2、CLAUDE.md 决策记录加 v22。
- 英文页同样改（`en`），中英结构检查要通过。
