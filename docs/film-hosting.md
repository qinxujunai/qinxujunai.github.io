# 影片的视频文件放在哪（2026-10-24）

《来不及爱你》在两个网站播放：个人网站首页首屏，影片网站 `too-late-to-love-you`。两边播的是同一个文件：他导出的 4K 网页版，51,065,030 bytes，SHA-256 `bf20447b5b94491280cef9ade0b1cd5bdad553aa8183b2f3d60335cd154768a8`（与影片仓库 `src/mobile-media-manifest.json` 一致）。

## 为什么不只放在 GitHub
他和大多数观众在国内。不开 VPN 时，GitHub Pages 上的视频点开只有声音或一直卡。2026-10-24 他在杭州，关掉 VPN，用手机在微信里打开测试页实测：

| 线路 | 起播 | 下载速度 |
| --- | --- | --- |
| 腾讯云上海 | 1.0 秒 | 9.1 Mb/秒 |
| Cloudflare R2 | 4.2 秒 | 4.2 Mb/秒 |

片子平均约 7 Mb/秒，所以腾讯云能一直流畅播放，Cloudflare 看久了会卡。

**注意**：QQ 浏览器里只有声音、没有画面，这是 QQ 浏览器的问题，换微信、系统浏览器都正常。别因为这个去改片子。

## 现在的做法：一个播放器，三个地址，浏览器自己往下换
```html
<video ...>
  <source src="https://media-1416754078.cos.ap-shanghai.myqcloud.com/too-late-to-love-you.mp4">  <!-- 1 腾讯云上海 -->
  <source src="https://media.praxisai.online/too-late-to-love-you.mp4">                          <!-- 2 Cloudflare R2 -->
  <source src="/too-late-to-love-you/media/film-mobile.mp4">                                     <!-- 3 GitHub 同源 -->
</video>
```
- 第一个地址打不开（比如腾讯云欠费停了、返回 403 或 404），浏览器自动试下一个。没有按钮、没有开关，看的人感觉不到。2026-10-24 在 Chromium 里验证过：前两个 404、403，自动播放了第三个。
- 局限：只在开始加载时换。播到一半断网，不会中途换。
- 个人网站的地址写在 `src/content.mjs` 的 `FILM_SOURCES`。`scripts/check.mjs` 只放行这三个，其他外部资源仍然不允许。
- 影片网站的地址写在 `scripts/build.mjs` 的 `SOURCES`。「下载影片」链到腾讯云：默认域名本来就返回 `Content-Disposition: attachment`，点了直接下载。

## 两处存储
**腾讯云：轻量对象存储（Lighthouse 版），上海**
- 存储桶 `media-1416754078`（AppId 1416754078），按量计费，他另买了一个 1GB 流量包（中国大陆通用，1 个月）。
- 管理入口不在「对象存储 COS」控制台，在「轻量应用服务器 → 对象存储」。在 COS 控制台里看是「暂无数据」，这是正常的。
- 存储桶访问权限是「公共读私有写」（他 2026-10-24 在控制台「属性设置」里设的），视频文件也单独设了公共读。实测：匿名能读视频，列不出桶里有什么（403），也写不进去（403）。
- 文件头：`Content-Type: video/mp4`、`Cache-Control: public, max-age=31536000, immutable`（同一台手机重看时尽量读缓存，不再算流量）。
- 腾讯规定：2024 年以后新建的桶，默认域名会强制下载（`x-cos-force-download`）。直接打开链接会下载，但放在网页的 `<video>` 里能正常播放，验证过。
- 这类桶是「role mode」：用 COS 接口改桶的 ACL 或策略会被拒绝。改单个文件的 ACL，子账号不行，主账号的密钥可以；也可以在控制台对文件点「权限」。

**Cloudflare：R2**
- 他的 Cloudflare 账号，存储桶 `media`（亚太），自定义域名 `media.praxisai.online`（域名 praxisai.online 在他的 Cloudflare 账号里）。
- 流量免费。国内能打开，但慢，只做备用。`r2.dev` 测试地址在国内常被拦，不要用。

## 换片子文件时（他提供新文件后）
1. 他说过不许转码、压缩、另出版本（**1080p 之类的版本永远不要提**，2026-10-24 他说「你这辈子都不要搞」）。新文件原样替换。
2. 先替换影片仓库 `media/film-mobile.mp4` 和 manifest 里的哈希。
3. 腾讯云：同名上传 `too-late-to-love-you.mp4`，带上面的两个文件头，再把这个文件设成公共读。上传时关掉 aws-chunked 编码，否则文件头里会多出 `Content-Encoding: aws-chunked`。
4. Cloudflare：同名上传，`Content-Type: video/mp4`。
5. 三个地址都下载一遍算 SHA-256，必须一致。
6. 文件名不变，网站就不用改。但旧文件缓存了一年：如果要立刻生效，改文件名，同时改两个仓库的地址。

## 费用与提醒
- 腾讯云上海：外网下行 0.5 元/GB，看完一次约 2.5 分钱。存储费可以忽略。先扣流量包，用完自动按量从余额扣。
- 他要在控制台设：资源包「用量预警」、费用中心「余额预警」。账户里只放少量钱：被刷流量最多扣完余额；停服后浏览器自动走 Cloudflare。
- 防盗链：轻量对象存储的控制台没有这个功能（只有文件列表、属性设置、挂载服务器、数据归档、存储监控），所以没开。
- 存储桶不能按 IP 限制次数，按 IP 限制要在国内 CDN 上做，而国内 CDN 要备案。

## 密钥
- 仓库里不存任何密钥。每次需要时，他在控制台新建、发给智能体，用完删除。
- 2026-10-24 用过的：Cloudflare 令牌「克劳德媒体」（R2 编辑 + DNS 编辑，他选了无有效期，说留着无所谓）；腾讯云一个子账号的密钥（只有 COS 权限）；腾讯云主账号密钥（用完已由智能体停用，需要他在「API 密钥管理」里点删除）。

## 试过、不要再走的路
- B 站嵌入、线路开关（v26.6–26.8，手机上卡死）。
- 只放 Cloudflare：国内 4.2 Mb/秒，低于片子码率。
- 腾讯 EdgeOne Pages：单文件上限 25MB；国内加速要备案；免费版不提供视频分发。
- 买服务器：带宽常见 3–6 Mb/秒，一个人都带不动，而且同样要备案。
- NAS、网盘：家里上行慢、运营商封端口；网盘的视频地址会过期、要登录，只能跳转。
- 彻底的方案是备案后用国内 CDN。现在不需要。
