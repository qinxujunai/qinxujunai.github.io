## 素材与视频

用户原始资料目录仍在本机，已加入 .gitignore；不上传相册数据库、内部交接说明或未选封面。
最终要求：不转码，不改原片，后续由用户自行替换。影片站的 `media/film-original.mp4` 与提供文件逐字节相同，SHA-256：`2e5547c7b3e209a6ac2b1c0393af8215f462ead887186c5cf04984db5bb71c45`。102,796,406 bytes（98.03MiB），3840×2160/24fps，H.264+AAC，57.087s。用户随后提供此 H.264，要求替换，本站未转码；最初 HEVC 文件留在本地原始资料，不上传。解码哈希与文件参数见影片站 `src/media-manifest.json`。

视频只在影片仓库存一份。影片站两个播放器引用同一个 URL，preload=none；用户播放或点击细读时间码后才下载。一个播放时另一个暂停。播放失败时显示原片下载；当前 H.264 已实际通过 Chrome/Edge 播放，仍不以模拟 UA 宣称实机兼容。原片替换同名文件后，若剪辑变化，必须重校时间轴、描述 VTT 和静帧。

原片大于50MiB会收到 GitHub 警告，但小于100MiB可用 Git 推送；网页上传限25MiB。来源：GitHub 官方 about-large-files-on-github。未使用 Git LFS。
