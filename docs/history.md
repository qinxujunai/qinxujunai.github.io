# 个人网站决策历史（v1–v27.26）

> 从 CLAUDE.md 移出的逐版决策记录，原文保留。当前规则见 AGENTS.md，近期决策见 CLAUDE.md。

- **v1（2026-10-19）**：单页个人站。首屏放他的一句话，作品按主次排列，三方复审后修订。
- **v2**：他说「这是个人网站，不是求职页」。
  - 去掉回款数字、客户名和来源标签。
  - 他还提到「长期主义」，说 easy vibe 的网页可以参考。
- **v3**：他说「太空了，没有设计，很短就完了」「你总要有一个对标」「参考苹果官网的设计」。
  - 按 apple.com 的语言重做：居中磁贴、黑色旗舰、蓝色文字链接、画廊。
  - 去掉 AI Work Method。
  - 加入 VoiceFlow 的 GitHub 数据，每 6 小时自动更新。
  - 他要求「最好能看出我的价值观」，于是加了「我在意的事」。
- **v4**，他提了这些要求：
  - 经历区的职位写法按他的意见改（细节不在本仓库）。
  - 「我在意的事……没有格局」：换成「思考」区，用他自己的方法论表达格局。
  - 加微信那里「太直白没有设计」：改成名片，可以保存成 PNG。
  - 「包括我的签名，够好了吗」：参照书法落款重新设计，加了朱印。
  - 「要突出 AI」。
  - 「每个项目甚至要展开说，到底为啥做，解决什么问题，技术架构，思路是啥」：网站从单页改为首页加六个案例页。
  - 经历区写不写客户名的决定，不在本仓库。
  - 「整个网站……用世界上最强的品牌营销的角度去审视修改」：全站文案重写，平台见 docs/copy.md。
  - 「github 里面也要有 readme 还有 claude md 文档」：也就是这份文件和 README。
- **v4.2（2026-10-20）**：
  - 去掉现任雇主和职位（见上文「现在」）。名片上写「用 AI 解决真实的问题」。
  - 他说 AI Signal「已经过时了」，要求先把项目本身做到顶级，再放进网站。于是重做了 AI Signal：
    - 修复停发：旧工作流因 60 天无提交被 GitHub 暂停，2026-07-22 之后没再发过。
    - 换信源。
    - 改为编号回填，模型写不出假链接。
    - 重新排版，参照 TLDR、The Rundown、Axios。
  - 案例页按 v3 重写；截图取自 v3 第一期的网页版。
  - AI Signal 的收件邮箱在该仓库的 Secret 里，不写进任何仓库文件。
  - 他要求：项目链接一律跳到项目的线上网站，不跳源码。「人要看的是作品，而不是代码」：全站不放 GitHub 和源码入口，正文不写程序名、文件名（如 audio_worker、prepare-digest），改用大白话。案例页顶部不再放「源码」，ai.vibecoding 的引用也链到线上站。

- **v4.3（2026-10-20）**：他说首页文字「太夸张了，搞得像面试一样」「不是 Demo 而是交付这种话很傻」，要求参考顶级个人网站，抓住项目的核心。
  - 全站改成个人网站的语气，新文案和原则见 docs/copy.md 开头。
  - 首页不再放 100%、20 分钟这类大数字；方案卡改成一句话 + 一行说明。
  - 「思考」区的大标题直接用他的原话，去掉我写的口号。
  - 「案例」统一改叫「作品」。

- **v5（2026-10-20，「希望是最后一次了」）**：他看完线上版说：
  - 「最后这里……别说啥把项目问题带过来，你要参考真正顶级的个人网站」：结尾改成「谢谢你看到这里。」「加个微信，交个朋友。」，再接名片和他的原话。不揽活。
  - 「这个项目为啥用这图片……github 应该有源代码，用你认为最好的展示这个项目方式」「有项目并且有网站的，想办法展示点网站」：每个作品首页直接放它的网站。桌面是浏览器窗口，手机是手机外框；区块吸顶，窗口里的网站随滚动往下翻。作品页顶部也换成同样的窗口。
  - 「什么脚本啥的，没有代码库的就没必要放了」：删掉三个没有代码库的工作案例页（中英共 6 页）。
  - 「我的影视作品啥的，我看之前有，被你删除了吗」：没删，是照片区在他手机上没加载出来（横向画廊里的懒加载）。改为不懒加载、低优先级。宣传片不放（见下）。
  - 「现在的名字刷新，感觉反而没那么好，多去参考苹果的交互和设计」：签名改为墨迹晕开再落印，滚出首屏后收进导航栏；首屏文字从下方带轻微模糊浮现。
  - 「easy vibe 要像分享 ai 价值一样，分享给别人，一句话，让人认可我，喜欢我，感觉有人情味，专业可靠，而且还能收获价值」：ai.vibecoding 从「方法」区升为「分享」：先逐字点亮他的原话，再一句说读者能拿走什么，三条他的原话，最后是网站窗口。
  - 首屏标题改为「我用 AI 做东西，也把想法分享出来。」。「从一句话，到能用的 AI」偏向求职定位，这一版他要的是个人网站。
  - 「思考」「方法」两区合进「分享」；导航为 作品 / 分享 / 经历 / 照片 / 联系。
  - 用三个审查代理做了对抗式审查（第一次在微信里点开的陌生人、苹果设计总监、挑剔的同行）。采纳：
    - 只有 VoiceFlow 吸顶，其余作品的网站随经过自然翻动；截图截短到一个区块的边上，按 2x 重截，窗口里的网页和滚动速度大致 1:1。手机长度少了约 20%。
    - 黑色区块下导航栏变深；宽屏磁贴通栏；首屏签名、标题拉开层次；分享区引文排成两行。
    - 「都能直接用」删掉（手机读者用不了 Windows 软件）；AI Signal「3 分钟」改「几分钟」（网页版标的是约 5 分钟）。
    - 首屏副句加上「以前拍片，现在做 AI」；结尾最后一行换成他的 manifesto：「AI 进化得越快，我们越需要慢下来……」。
    - 作品页按仓库文档改准：VoiceFlow 写「私有内存」「停止到发出粘贴」，并补上「确认不了文字真的进了输入框」；AI Signal 写明只发到他自己的邮箱、模型可能引错编号；万象成文平台写「3 个已验证 + 3 个时好时坏」。
  - 宣传片：他说「没有，那就没必要，太久远了，视频太大了」。不放视频，影像只保留照片区。
  - 没采纳：把经历和照片移到作品前面（他要第一眼看到作品）；AI Signal 改成全宽窗口（邮件本身是 640 宽的单栏，全宽反而空）。

- **v6（2026-10-20）**：他说副句「可能强化别人觉得你不是 ai 相关的」，首屏要「让人看完有收获」，可以推荐 easy vibe；印章「感觉被挤压了」；要求用乔布斯、苹果顶级产品经理、UI/UX、字节 AI 产品经理面试官、顶级投资人的标准，加标杆网站对抗式审查，「你有权改动所有」。
  - 三份审查：设计、面试官加投资人、19 个标杆站实测。
  - 首屏标题一度换成他的原话「先立边界，再把概率压成确定性。」，他看了说「你自己不觉得傻逼吗，顶级的个人网站你看不到吗」：方法论不是自我介绍。改成顶级个人网站的开法（rauno.me、karpathy.ai、paco.me），一句大白话：**「我是秦徐俊，做 AI 产品。」** 副句：「做过几年内容和运营，所以做任何东西，我都先想：人为什么会用它。下面是我做的三个产品，还有我用 AI 做事的方法。」
  - 作品下面的「判断句」（如「剪贴板没核对过，不算送达」）同理太技术，首页改回大白话规格，判断留在作品页里。
  - 「我是秦徐俊，做 AI 产品」他也否了：「两边秦徐俊，谁在乎你是谁」；我给的三个两拍口号他说「像逗小学生」。实测标杆站的首屏后定稿：
    - 标杆实际怎么做：brianlovin.com、emilkowal.ski、paco.me 都是一句平实的陈述加作品列表，没有口号；apple.com.cn 是产品名加产品画面，产品就是主角。
    - 所以首屏 = 签名 + 一句平实的话「我做 AI 产品，从想法到上线。下面四个，都已经上线。」（21–28px，中等字重，不是大标题）+ 四张作品卡（真实网站截图 + 名字 + 一行它是什么），再加「加我微信」。ai.vibecoding 的卡直接链到线上站。
    - 教训：首屏不要写口号或方法论；让作品自己出场。
  - 他接着要求：「对所有文字都用这种标准审视一遍，然后一次性改好……用苹果的所有标准去做这个网站。」全站文案按 apple.com.cn 实测的规则重写一遍，规则写进 docs/copy.md「文案标准」：
    - 首屏一句话去掉重复的「上线」：「我做 AI 产品，从想法到上线。」
    - 经历区标题改写（细节不在本仓库）。
    - 作品页小标签统一成两个字：起因、难点、边界、架构、取舍、验证、历程、还差什么。
    - 链接统一为「访问网站 ›」「进一步了解 ›」「开始阅读 ›」；影像说明统一成名词短语；VoiceFlow 架构里的状态机写法改成白话。
  - 首屏最后由他本人定（「不如我之前的……排版是有头像那个，但是标题应该是大标题那版的标题」）：头像、签名、大标题「我用 AI 做东西，也把想法分享出来。」、副句列出四样作品（不提新媒体）、「加我微信」「看看作品 ›」。作品卡和平实一句话那版撤掉。以后首屏不要再改，除非他提。
  - 副句一度列了四样作品，他说「锚定这几个作品，那不就限制死了……不要太具象，而是价值观一点」，并要我按品牌设计思路自己定，不要问他。按「标题说做什么、副句说为什么、用创始人自己的话」，副句改为他的原话，并按他的要求把「让你」改成「让人」：「让 AI 负责拆解、生成与验证，让人守住目标、边界与品味。」（「首页是面向所有人的」）
  - 他要求标题「做法」改成「想法」：「我用 AI 做东西，也把想法分享出来。」头像原来裁得太紧，头顶被切掉，改为更宽的裁切。；分享区的大字随之换成他的另一句原话「用自然语言，创造可运行的作品。」
  - 首屏加一行文字链接到 ai.vibecoding。首屏去掉头像（脸留在名片上），签名放大，成为首屏唯一的主角。
  - 印章确实变形：两个字被纵向拉长约 2.1 倍。改成竖印，「徐」上「俊」下，等比缩放。深色模式下印章红提亮。
  - 一屏一颗蓝色按钮：导航的「加微信」等首屏滚走后才出现。
  - 删掉「作品」标题磁贴。
  - 历史版本曾在经历区突出工作成果；本公开站已不展示。
  - 影像标题「一张人台照，变成一组模特图。」，照片减到 4 张。
  - 页脚加一行说明网站怎么做的：纯 HTML 和 CSS、系统字体、无外部请求（v7.2 删掉）。
  - 修了一个老问题：分词时保持短语不断开的「不换行空格」其实是普通空格，「约 18 分钟」这类短语会被拆开。
  - 没做：首屏用胶囊打字做自我介绍（和 VoiceFlow 段重复）；「最近在想」区块（要他本人给内容）。

- **v7（2026-10-20）**：他和朋友刘在手机上看完，问题是「看不懂、看着累、加微信麻烦」：
  - 「不要超过三种字体，字体不统一」「也不要反复秦徐俊秦徐俊」：只留系统黑体 + 楷书标志；名片去掉打字的名字和网址，页脚去掉名字。
  - 「往下一滑，不应该是手机的模板……不知道是滑手机里面还是外面，因为不是一个软件在手机的」：手机上去掉手机外框，改成 16:10 浏览器卡片（真实网址 + 网页顶部），不在框里滚动。
  - 「对于每一个项目的介绍不够直白……就像短视频三秒……苹果不需要让人知道我是什么东西，但是我们自己的项目，得让别人知道是什么」「点进一步了解后的网站，内容也比外面好多了」：每个作品一句大白话说清是什么、帮你做什么。
  - 刘：「展示完全」「只要二级文字，不要三级，或者三级放在这里（截图下方）」：作品区块只有名字 + 一句话在图上方，事实和链接放图下方，手机上一屏看完；顺手修了 VoiceFlow 标题被切掉一半（吸顶区块垂直居中溢出）。
  - 「标点符号太多了，看的眼睛累」「背景是黑白灰，哪一个是重点」「经历的字体、时间、公司……有点抢注意力」：标题和单行文字去掉句末句号；文字只用三档颜色；经历重排（时间在上、13px 灰，职位为唯一重点，描述用正文色）。
  - 「图片如果也是作品，放前面……分享的内容和 vibecoding 冲突了，让人看不懂」：AI 视觉成为第四个作品；「分享」改「想法」，引文块和 ai.vibecoding 窗口合成一个区块，三条原则移出首页。
  - 「图片展示那里切换的时候……卡住图片，只显示一半」：翻页改为每次正好一张，触屏设备隐藏按钮直接滑。
  - 「爱短链……点击直接跳转微信添加」：调研后，个人微信没有任何链接能从浏览器一键加好友，爱短链最后也是长按二维码，还要付费、用第三方域名。做法：微信里长按二维码直接加；手机浏览器里「复制微信号，打开微信」（等他提供微信号）；电脑上扫码。企业微信获客链接能真正一键，但加到的是企业微信，他想要再换。
  - 手机截图改用专门的 16:10 小图（8–17 KB），首屏只预加载 VoiceFlow 这一张；弱网首屏 1.9 秒。
